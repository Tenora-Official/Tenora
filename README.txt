TENORA site
1. Supabase -> SQL Editor: run setup.sql, setup-collections.sql, setup-orders.sql (each once; skip ones you already ran, but setup-orders.sql is new).
2. Supabase -> Authentication -> Users: make sure you have an admin user (email + password).
3. Replace 94000000000 with your real WhatsApp number in index.html and cart.js; set bank details in cart.js.
4. admin.html = orders, products, gift collections + prices (login with that admin user).
5. Upload the whole folder to your host.
